# Simple Calculator:

Description:

This is a simple calculator project developed using JavaScript. It performs basic mathematical operations using if...else statements.

Features:

Addition (+)

Subtraction (-)

Multiplication (*)

Division (/)

Modulo (%)

Handles division by zero and modulo by zero.
Displays an error message for invalid operators.




# Student Marks Details
Description

This is a simple JavaScript project to calculate student marks, add bonus marks, validate marks, and determine grades based on the final score. It uses different JavaScript conditional statements and operators to process student marks.

Features

Validates marks between 0 and 100.

Adds bonus marks based on the given conditions.

Ensures the final marks do not exceed 100.

Calculates grades based on marks.

Displays pass or fail status.

Displays messages based on the student's grade.
